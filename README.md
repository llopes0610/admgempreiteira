# Empreiteira Site

Site institucional premium para empreiteira, desenvolvido com Next.js, React, TypeScript e Tailwind CSS 3.

## Instalação

```bash
npm install
npm run dev
```

Acesse:

```text
http://localhost:3000
```

## Build de produção

```bash
npm run build
npm start
```

## Estrutura

- `src/app`: páginas e rotas
- `src/components`: componentes visuais
- `src/data`: dados de serviços e projetos
- `src/types`: tipos TypeScript
- `public/images`: imagens
- `public/videos`: vídeos
- `public/logos`: identidade visual
